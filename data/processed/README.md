# 處理後資料

本目錄保存通過驗證且可供分析的衍生資料。

- `wanhua-community-associations.json`：由臺北市政府來源快照產生、最小化個資的萬華協會資料庫。
- `wanhua-community-activity-statistics.json`：Sprint 2 核定方案年度、類型與協會覆蓋統計。
- `wanhua-community-sdg-candidate-statistics.json`：Sprint 3 待人工覆核候選的工作量分布；不是正式 SDG 涵蓋率。
- `data-layer-examples.xlsx`：六組示例資料的人工檢閱工作簿，包含型別化日期、數字、篩選與公式計算的 AI 總分。

所有處理後產物必須可由已記錄來源與轉換規則重製，且不得覆寫 raw 或 external 來源快照。
