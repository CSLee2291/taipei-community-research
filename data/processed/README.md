# Processed Data

This directory contains validated, analysis-ready derivatives.

- `wanhua-community-associations.json` is the privacy-minimized Wanhua association database generated from the preserved Taipei City source snapshot.
- `data-layer-examples.xlsx` is a review workbook containing the six sample datasets, typed dates and numbers, filters, and a formula-driven AI ranking total.

Processed outputs must be reproducible from documented sources and transformation rules. They must never overwrite raw or external source snapshots.
