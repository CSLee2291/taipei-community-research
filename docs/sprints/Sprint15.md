# Sprint 15 — 證據式 SWOT 分析

狀態：規格已建立，尚未執行。

## 目標

為每個社區產生具來源、可人工覆核的優勢、弱勢、機會與威脅候選分析。

## 任務

1. 定義 SWOT 證據規則、時間範圍與人工覆核狀態。
2. 以已驗證 Profile、活動、獎項、補助、照顧、志工與年度計畫提出候選。
3. 每個敘述附來源、證據日期、信心與限制。
4. 產生社區別 SWOT Markdown、彙整 `SWOT.md` 與 Dashboard 資料。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- AI 只能提出候選，未經人工覆核不得標示為正式結論。
- 資料缺少不是弱勢，查無公開資料不是威脅。
- 內部與外部因素定義一致，避免重複與價值偏見。
- 每項結論可回溯至至少一個適切來源。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 16。
