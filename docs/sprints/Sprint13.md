# Sprint 13 — 官方數位管道研究

狀態：規格已建立，尚未執行。

## 目標

查核協會官方網站與社群管道，建立透明、可重複的社區數位能力評估資料。

## 管道

- 官方網站
- Facebook
- LINE 官方帳號
- Instagram
- YouTube

## 任務

1. 逐一確認頁面是否由協會或主管機關正式管理。
2. 記錄網址、平台、首次／最後驗證日期、可用狀態與身分證據。
3. 建立 `CommunityDigital.csv`、JSON、schema 與資料字典。
4. 定義數位能力指標與資料不足處理方式。
5. 產生 Digital Dashboard 資料與 Markdown 分析。
6. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 不因同名或地理位置相近就推定官方身分。
- 不收錄個人帳號、私人群組邀請或非公開聯絡資料。
- 網路聲量不直接等於治理品質或社區影響力。
- 評估公式、期間與缺值規則公開且可重製。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 14。
