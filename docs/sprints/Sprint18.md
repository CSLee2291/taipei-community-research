# Sprint 18 — 公開研究網站

狀態：規格已建立，尚未執行。

## 目標

建立可由 GitHub Pages 發布、無需秘密金鑰即可閱讀核心內容的公開研究網站。

## 功能

- 社區頁面
- 搜尋與篩選
- 社區比較
- 資料與報告下載
- 響應式與可近用介面

## 任務

1. 以同版驗證資料產生網站內容與導航。
2. 顯示研究範圍、資料日期、方法、來源、授權與限制。
3. 建立搜尋、篩選、比較及穩定的社區頁面 URL。
4. 確保核心內容在沒有 Google Maps API Key 時仍可閱讀。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 靜態建置、內部連結、下載檔、HTML 語意與響應式檢查通過。
- 不發布敏感、未授權或未覆核內容。
- 網站與 Dashboard、資料及報告版本一致。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 19。
