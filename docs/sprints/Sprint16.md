# Sprint 16 — Top 5 社區遴選

狀態：規格已建立，尚未執行。

## 目標

在資料與人工覆核足夠時，以公開、可解釋的資格與評分規則產生 Top 5 社區；若條件不足，發布 `not_scorable` 說明而不強排名。

## 評估面向

- 政府評鑑
- 可驗證活動
- SDG 與公共價值
- 創新
- 社區照顧
- 經人工覆核的 AI 輔助分數

## 任務

1. 先執行評分資格、資料完整性、信心與公平性檢查。
2. 依 `docs/evaluation-model.md` 計算分數並進行敏感度分析。
3. 產生 `Top5.md`、比較表、雷達圖與可重製的評分輸出。
4. 公開模型版本、證據筆數、信心、並列與缺值規則。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 只有 `eligible` 且經人工覆核者能列入正式名次。
- 不以資料量、社群聲量或政府補助金額代替影響力。
- 權重變動與缺值處理不應造成未揭露的順位扭曲。
- 不足五個合格社區時不得補足名額。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 17。
