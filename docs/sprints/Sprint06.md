# Sprint 06 — 政府資料查核

狀態：規格已建立，尚未執行。

## 目標

以官方政府來源逐筆覆核萬華區社區發展協會主檔，補齊可公開且能回溯來源的組織資料。

## 來源範圍

- 臺北市資料大平臺
- 臺北市政府社會局
- 臺北市萬華區公所
- 衛生福利部
- 環境部

## 任務

1. 先閱讀 `AGENTS.md`、`PROJECT_SPEC.md`、`ROADMAP.md`、研究方法與資料字典。
2. 逐筆查核正式名稱、公開組織負責人、組織地址、公開組織電話、成立日期與社區類型。
3. 保存來源標題、發布者、網址或識別碼、資料日期、存取日期、授權與證據等級。
4. 更新 `data/csv/CommunityProfile.csv` 與對應 JSON。
5. 產生 `docs/VerificationReport.md`，列出來源衝突、缺值與 TODO。
6. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- CSV、JSON、schema、唯一鍵及來源欄位驗證通過。
- 查無資料者保持空值，不寫成沒有組織或未營運。
- 個人姓名與聯絡資料只有在官方來源明確作為組織公開聯絡資訊時才可收錄。
- 不公開私人電話、電子郵件或其他研究不必要的個人資料。
