- Final README

1. 確認 main、GitHub Pages、資料、Dashboard、網站及報告指向同一 commit。
2. 建立 `v1.0.0` tag、GitHub Release、資產與校驗資訊。
3. 公開來源截止日、schema／模型版本、授權、引用方式與已知限制。
4. 若使用 DOI 或 Zenodo，先取得使用者明確授權並保存正式識別碼。
5. 更新 README、CHANGELOG 與 ROADMAP 為最終狀態。

## 驗收條件

- Sprint 21 沒有未解決 release blocker。

- 正式輸出不含秘密、私人資料、未標示合成資料或未覆核排名。
- 發布後完成最小 smoke test 與回復紀錄。
