# Sprint 20 — GitHub Pages 部署

狀態：規格已建立，尚未執行。

## 目標

將通過驗證的網站、Dashboard、資料與研究報告部署至 GitHub Pages，完成 v1.0 發布候選版。

## 任務

1. 驗證官方 Build → Upload Pages Artifact → Deploy 工作流程。
2. 確認 `main` 部署來源、Pages 權限、environment 與 concurrency。
3. 驗證網站、Dashboard、資料下載、報告與資產路徑。
4. 產生發布候選版說明、README 與 CHANGELOG 更新。
5. 記錄部署 URL、commit SHA、資料版本及回復程序。

## 驗收條件

- GitHub Pages 部署成功且可由無登入瀏覽器存取。
- 深層連結、相對路徑、行動裝置與無 API Key 狀態正常。
- 線上內容與同一 commit 的資料、Dashboard 及報告一致。
- 本 Sprint 不建立最終 `v1.0.0` Release；最終發布留給 Sprint 22。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 21。
