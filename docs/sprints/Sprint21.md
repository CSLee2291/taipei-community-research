# Sprint 21 — 品質保證

狀態：規格已建立，尚未執行。

## 目標

對整個 Repository、研究資料、引用、Dashboard、網站與 GitHub Pages 進行 v1.0 發布前品質保證。

## 檢查項目

- Repository 內部連結與外部引用來源
- CSV schema、型別、唯一鍵、外鍵及缺值
- JSON schema 與 CSV／JSON 同步
- 合成資料隔離與敏感資料檢查
- Dashboard 建置、測試、lint 與基本可近用性
- 網站與 GitHub Pages 深層連結、下載及跨裝置測試
- 報告表格、圖表、引用與版本一致性

## 交付

- QA 報告
- 問題清單、嚴重度與處理狀態
- 可重製的檢查命令或自動化
- Release blocking／non-blocking 判定

## 驗收條件

- 所有 release blocker 已修正並重新驗證。
- 未修正限制有負責人、原因與公開說明。
- QA 不修改研究結論來掩蓋資料問題。

## 完成流程

更新 README、CHANGELOG、ROADMAP，建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 22。
