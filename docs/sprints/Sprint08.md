# Sprint 08 — 社區活動時間軸

狀態：規格已建立，尚未執行。

## 目標

研究並呈現 2023、2024、2025、2026 年可驗證的社區活動與方案時間軸。

## 任務

1. 先覆核既有活動資料的證據邊界與重複紀錄。
2. 蒐集活動日期或明確期間、類型、場地、對象與來源。
3. 區分核定、預定、執行中、完成及成果等不同證據狀態。
4. 更新 `CommunityActivities.csv`、JSON 與 `ActivityTimeline.csv`。
5. 產生年度統計、圖表、Markdown 摘要與 Dashboard 資料。
6. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 每筆活動有協會外鍵、時間、來源、存取日與證據等級。
- 核定或預定資料不得解讀為已完成。
- 預計人數不得寫入實際參與人數。
- 合成示例不得進入正式統計。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 09。
