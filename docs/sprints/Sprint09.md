# Sprint 09 — 政府獎項與認證

狀態：規格已建立，尚未執行。

## 目標

蒐集可由政府或頒獎機構官方來源驗證的社區獎項、認證與公開肯定。

## 來源範圍

- 臺北市政府與所屬機關
- 衛生福利部
- 環境部
- 其他可驗證的官方頒獎機構

## 任務

1. 建立獎項名稱、頒發機構、層級、日期、結果、來源與證據狀態。
2. 更新 `CommunityAwards.csv` 與 JSON。
3. 產生 `Awards.md` 與年度／類型摘要。
4. 將同一獎項的提名、入選、得獎與認證狀態分開。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 每筆紀錄有官方來源並能解析至社區主檔。
- 查無公開獎項不等於沒有得獎。
- 不以獎項數直接形成社區績效排名；若需要評分，必須遵循評分模型與資格門檻。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 10。
