# Sprint 10 — 政府補助與資源分析

狀態：規格已建立，尚未執行。

## 目標

研究政府補助計畫、核定資源與社區專案，建立可審核的資金資料層。

## 任務

1. 蒐集補助計畫、補助機關、申請或核定狀態、期間、金額與官方識別碼。
2. 明確區分申請額、核定額、共同負擔與核銷支出。
3. 更新 `CommunityFunding.csv` 與 JSON。
4. 產生 `FundingAnalysis.md`、年度統計與 Funding Dashboard 資料。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 金額、幣別、會計年度及狀態有明確欄位。
- 核定金額不得推論為實際支出或成果。
- 不跨年度重複加總同一計畫。
- 合成補助資料排除於正式分析。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 11。
