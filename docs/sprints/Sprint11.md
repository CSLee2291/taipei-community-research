# Sprint 11 — 社區照顧關懷據點

狀態：規格已建立，尚未執行。

## 目標

研究萬華區社區照顧關懷據點及其可驗證的服務內容。

## 任務

1. 以政府據點名冊及官方服務資料確認營運單位、地址、服務期間與狀態。
2. 蒐集健康促進、共餐、餐食服務、關懷訪視與電話問安等服務。
3. 建立 `CareStation.csv`、JSON 與資料字典／schema。
4. 產生 Care Dashboard 資料與 Markdown 摘要。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 區分協會、據點與服務，不因名稱相近直接視為同一實體。
- 服務存在、服務頻率與實際受益人次分別需要對應證據。
- 不公開服務對象的個人資料或敏感健康資訊。
- 查無據點資料保持未知並建立 TODO。

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 12。
