# Sprint 12 — 志工系統研究

狀態：規格已建立，尚未執行。

## 目標

建立社區志工組織、培訓、人數與服務的可追溯研究資料。

## 任務

1. 蒐集志工隊或組織、訓練課程、服務類型、服務期間與公開統計。
2. 區分登錄志工數、活躍志工數、服務人次與服務時數。
3. 建立 `Volunteer.csv`、JSON、schema 與資料字典。
4. 產生 Volunteer Dashboard 資料及 Markdown 分析。
5. 更新 README、CHANGELOG 與 ROADMAP。

## 驗收條件

- 每個統計值有期間、單位、來源與計算定義。
- 不從活動照片或社群貼文推估志工人數。
- 不收錄志工姓名、電話或其他私人資料。
- 未驗證數據保持空值並列為 TODO。

## 完成流程

建立單一 Sprint commit 與 Pull Request；不得開始 Sprint 13。
