# Dashboard

This directory will contain the interactive research dashboard, reusable visualization components, and dashboard-specific tests.

## Expectations

- Read only approved, processed data products.
- State data version, coverage period, and last update visibly.
- Provide source and methodology links near derived metrics.
- Meet responsive-design and accessibility requirements.
- Keep generated exports in `dashboard/output/` rather than source control.

The implementation stack will be selected after the data model and user needs are defined.
